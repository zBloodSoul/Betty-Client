Sign-in & security

Betty uses only the official, documented sign-in flow. Your password is entered on Microsoft's own page and is never seen or stored by Betty.

  1. Microsoft sign-inThe player signs in on Microsoft's official page (OAuth 2.0 with PKCE, registered public client).
  2. Xbox Live & XSTSThe Microsoft token is exchanged with Xbox Live for an XSTS token, exactly as the official launcher does.
  3. Minecraft servicesThe XSTS token is exchanged for a Minecraft access token, and game ownership is checked before anything can be launched.
  4. Official game filesThe game, libraries and assets are downloaded only from Mojang's servers and verified with SHA-1 before launch.
  5. Stored safelyThe refresh token is kept only on the player's PC, encrypted with Windows DPAPI. Signing out deletes it.

FAQ

Is Betty Client available?

Not yet. Betty is in development and is currently used only for testing. This page will be updated when it is released.

Do I need to own Minecraft?

Yes. Betty requires a Microsoft account that owns Minecraft: Java Edition and checks ownership before launching.

Which version of Minecraft does it support?

Minecraft: Java Edition 1.8.9 on Windows.

Does Betty collect my data?

No. Betty has no servers of its own and sends nothing to us. See the Privacy Policy.
